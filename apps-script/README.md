# Apps Script 버전 (구글 도메인으로 제공)

`vercel.app`이 막힌 망에서 접속하기 위한 버전입니다. 같은 화면을 구글 Apps Script 웹앱으로 제공하고,
목록 데이터는 소유자 구글 드라이브의 `ismp-poc-downloads.json` 파일에 저장됩니다.

## 파일

| 파일 | 설명 |
|---|---|
| `Code.gs` | 서버 코드 (조회, 비밀번호 확인, 저장) |
| `Index.html` | 화면. `build_index.py`가 `../index.html`에서 생성합니다. |
| `build_index.py` | 화면 변경 후 `python build_index.py`로 `Index.html`을 다시 만듭니다. |

## 배포 순서

1. https://script.google.com 에서 **새 프로젝트**를 만듭니다. 이름은 `ISMP PoC Download` 등으로 정합니다.
2. 기본 `Code.gs` 내용을 이 폴더의 `Code.gs`로 교체합니다.
3. 왼쪽 **파일 +** 에서 **HTML**을 추가하고 이름을 `Index`로 지정한 뒤, 이 폴더의 `Index.html` 내용을 붙여넣습니다.
4. **프로젝트 설정 > 스크립트 속성 > 속성 추가**에서 `ADMIN_PASSWORD`를 만들고 값에 관리자 비밀번호를 입력합니다.
5. **배포 > 새 배포 > 유형: 웹 앱**을 선택합니다.
   - 다음 사용자로 실행: **나**
   - 액세스 권한이 있는 사용자: **모든 사용자**
6. 처음 배포할 때 권한 승인(드라이브 접근) 창이 나오면 승인합니다.
7. 발급된 `https://script.google.com/macros/s/.../exec` 주소를 공유합니다.

## 코드를 수정한 경우

**배포 > 배포 관리 > 편집(연필) > 버전: 새 버전 > 배포**를 해야 같은 주소에 반영됩니다.
새 배포를 만들면 주소가 바뀝니다.

## 알아둘 점

- 비밀번호는 코드가 아니라 스크립트 속성에만 저장됩니다.
- 목록 파일(`ismp-poc-downloads.json`)은 배포한 계정의 드라이브 최상위에 자동 생성됩니다. 삭제하면 목록이 초기화됩니다.
- 하루 실행 시간 등 Apps Script 할당량이 있으나 이 용도에서는 문제되지 않습니다.
